# Data sumber

CSV mentah tidak didistribusikan dalam repo ini. Notebook memakai file yang diberikan pemilik proyek,
dengan nama `churn.csv` atau `Churn_Modelling.csv`, dan memeriksa SHA-256:

`3996cd1fa372e0db0cd9c0ebac35bbd4e8e3c65fb942bb010c826e7b1eeef0a0`

Identitas file Drive ada pada konfigurasi notebook; itu jejak file yang diperiksa, bukan bukti penerbit
awal atau lisensi redistribusi. Periode pengamatan, horizon churn, mata uang, dan penerbit awal belum
dikonfirmasi. Gunakan data yang memang dapat Anda akses dan gunakan.

Untuk eksekusi lokal, letakkan CSV di root repo. Untuk Colab, unggah melalui panel Files bila unduhan
dari sumber tidak dapat diakses. Pertahankan strict hash untuk snapshot referensi. Sumber baru memerlukan
peninjauan sebelum menonaktifkan strict hash.

`examples/synthetic_customers.csv` berisi tiga profil buatan untuk demonstrasi form batch. Baris tersebut
bukan catatan nasabah aktual dan tidak mengandung label untuk menilai akurasi.
